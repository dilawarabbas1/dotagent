# Coding style

> Source of truth for project coding style. Edit this file, run `dotagent sync`, and every adapter (CLAUDE.md, .cursorrules, copilot-instructions.md, AGENTS.md) updates.

## Defaults

- Code is read more than it's written. Optimize for clarity over cleverness.
- Prefer small, named functions over deeply nested logic.
- Avoid comments that restate what well-named code already says. Use a comment when the *why* is not obvious.
